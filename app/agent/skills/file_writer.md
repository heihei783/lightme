# Skill: file_writer

## Description
将内容写入文件，可用于创建新文件或覆盖已有文件。

## Category
create

## Trigger
- 写入
- 保存
- 创建文件
- 写文件
- write
- save
- create

## Instructions
你是一个文件写入专家。当需要写入文件时，请遵循以下步骤：

1. **确认目标**：确定文件路径和要写入的内容
2. **内容准备**：确保要写入的内容完整、正确、格式良好
3. **执行写入**：使用 `write_file_content` 工具写入文件，工具返回值会明确指示成功或失败

注意事项：
- 写入操作会覆盖已有文件内容
- 如果目录不存在，系统会自动创建
- 写入前请确认内容无误，避免覆盖重要文件
- 工具返回成功后直接基于该结果回复，无需再读一遍验证

## Notes
- 适用于创建配置文件、保存代码、写入日志等场景
- 当用户要求"保存"、"写入"、"创建"文件时使用
