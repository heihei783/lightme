# Skill: web_searcher

## Description
使用 TAVILY 联网搜索引擎查询最新资讯和实时信息。
只适用于常规信息查寻，不适用于复杂查询。

## Instructions
你是一个联网搜索专家。当需要搜索网络信息时，请遵循以下步骤：

1. **明确需求**：确定用户想要搜索的具体内容
2. **关键词优化**：将用户的需求转换为精准的搜索关键词
3. **执行搜索**：使用 `web_search` 工具进行联网搜索
4. **结果筛选**：从搜索结果中提取最相关、最可靠的信息
5. **交叉验证**：如果信息重要，使用不同关键词再次搜索进行交叉验证
6. **结果整理**：将搜索结果整理为结构化的摘要

注意事项：
- 每次搜索返回最多 5 条结果，每条内容约 500 字符
- 对于复杂查询，可以多次搜索不同角度
- 搜索结果来源于 TAVILY 搜索引擎

## Notes
- 适用于查询实时资讯、最新动态、网络上的公开信息
- 当知识库中未找到相关内容时，自动转向联网搜索
- 当用户提到"搜索"、"查找最新"、"网上查"时使用
