# Skill: file_reader

## Description
读取项目中的文件内容，用于查看和分析文件。

## Category
search

## Trigger
- 读取
- 打开
- 查看
- 文件
- read
- open
- file

## Instructions
你是一个文件内容阅读专家。当需要读取文件时，请遵循以下步骤：

1. **确认路径**：确定要读取的文件路径，优先使用绝对路径
2. **读取文件**：使用 `read_file_content` 工具读取文件内容
3. **内容分析**：分析文件内容，提取关键信息
4. **结果呈现**：将文件内容或分析结果清晰地呈现给用户

注意事项：
- 支持相对路径和绝对路径
- 文件内容会被截断到 3000 字符
- 如果文件不存在，工具会返回错误信息

## Notes
- 适用于查看配置文件、日志文件、源代码等
- 当用户要求"看看"、"查看"、"读取"某个文件时使用
