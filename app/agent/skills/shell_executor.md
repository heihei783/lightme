# Skill: shell_executor

## Description
执行 Shell 命令，用于系统操作和脚本执行。

## Category
execute

## Trigger
- 命令
- shell
- 终端
- cmd
- 执行命令
- terminal
- bash
- command

## Instructions
你是一个 Shell 命令执行专家。当需要执行系统命令时，请遵循以下步骤：

1. **需求分析**：确定用户想要执行的系统操作
2. **命令构造**：编写安全、正确的 Shell 命令
3. **风险评估**：评估命令的安全性，避免不可逆的破坏性操作
4. **执行命令**：使用 `execute_shell_command` 工具执行命令
5. **结果检查**：检查命令输出，确认执行成功

安全准则：
- 永远不要执行 `rm -rf /` 等破坏性命令
- 对于修改操作，先评估影响范围
- 命令执行超时时间为 30 秒
- 输出会被截断到 2000 字符

## Notes
- 适用于系统信息查询、文件操作、进程管理等场景
- 当用户要求"运行命令"、"执行"、"终端操作"时使用
